# Mall-Network-Design



Mall Network Design (Cisco Packet Tracer)
A secured star-topology network for a shopping mall, designed and configured in Cisco Packet Tracer.
Network Design
1 central router connected to 6 switches, one per department: Management Office, Retail Shop, Security Office, Visitor Wi-Fi Zone, IT Department, Food Court (POS)
12 PCs, 2 per department
A separate subnet for each department (192.168.1.0 to 192.168.6.0, /24)
Default gateway configured on every switch
Security Configuration
Console, VTY, and privileged-mode passwords
Encrypted passwords (service password-encryption)
SSH enabled with 1024-bit RSA keys; Telnet disabled
Login banner and session timeout
Local user authentication (AAA)
Documentation
A report covers the build steps, device configurations, connectivity tests, and research on firewalls, IPS, VPN, and endpoint security.
How to Open
Open Mall_Network.pkt with Cisco Packet Tracer.
